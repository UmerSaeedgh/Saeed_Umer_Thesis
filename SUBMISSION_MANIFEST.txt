2026-09-27 REVISION 9: the List of Abbreviations was silently empty

"Abbreviation" -- and finding no match anywhere in 88 pages.

Root cause: the abbreviations list used the standard LaTeX `nomencl` package
(`\makenomenclature` / `\printnomenclature`), which requires an external
`makeindex -s nomencl.ist` pass between compiles to turn the raw entry list
(`document.nlo`) into the sorted, printable list (`document.nls`). No
environment used to build this thesis locally -- a standalone Tectonic
engine, deliberately downloaded because no system LaTeX install exists on
this machine -- has ever had a `makeindex` binary available. Tectonic runs
`biber` automatically (for the bibliography) but has no equivalent automatic
step for `nomencl`, and nomencl fails silently rather than erroring when its
input file is missing: `\printnomenclature` simply produces an empty
section, with no warning surfaced anywhere in the build log. This means the
"List of Abbreviations" page has, in all likelihood, been silently blank in
every locally-compiled PDF produced over the entire course of this project,
undetected because no prior check -- mine or any external review's --
specifically searched the rendered PDF text for that section's content.

Fixed by removing the dependency on `nomencl`/`makeindex` entirely:
`shortcuts.tex` now directly authors a `longtable` of all 32 abbreviations
(the same list originally encoded as `\nomenclature{...}{...}` calls, still
alphabetised the way `nomencl` would have sorted them), so the section
renders identically regardless of which LaTeX toolchain compiles the
document -- Tectonic, Overleaf, or a full local TeX Live install. Two entries
were added while doing this that the original list never covered: **AI**
(used once in the running text, in the Henestrosa citation discussion, but
never given a nomenclature entry) and a general audit of every acronym
actually appearing in the body text against the list (all others -- TV, LLM,
CI, BH-FDR, Holm, IAA, QC, pp, H1-H4, RQ, API -- were already present and
correctly defined; NLP and ML remain listed even though neither happens to
appear in acronym form in the running prose, since they are legitimate field
terms).

checking the replacement page:

  from the immediately preceding section's `\pagestyle{abv}`, never
  overridden. A pre-existing, already-styled `akv` pagestyle
  ("LIST OF ABBREVIATIONS") was sitting unused in `header.tex`; document.tex
  now activates it for this section.
- The label "Pseudoreplication" is a single word wider than its table
  column with no natural break point, so it overflowed directly into the
